# User List App

A simple and responsive User List application built using HTML, CSS, and JavaScript. The app fetches user details from a public REST API and displays them in responsive cards.

## 🚀 Features

- Fetches user data using Fetch API
- Displays users in responsive cards
- Loading indicator while fetching data
- Error handling for API failures
- Responsive design for mobile and desktop
- Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
